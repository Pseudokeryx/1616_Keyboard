# 1616 Keyboard

This is the repository for the 1616 Keyboard.

1616 Keyboard is a custom keyboard made for Android.

## 1. Download

- Go to [https://github.com/Pseudokeryx/1616_Keyboard/releases/tag/Beta](https://github.com/Pseudokeryx/1616_Keyboard/releases/tag/Beta)
- Click on **app-debug.apk**

## 2. Installation

After downloading the **app-debug.apk** file, the installation dialogue should automatically open. Otherwise, you can find the file on your Android device's Downloads directory.

## 3 Keyboard Setup

- In your Android device's settings, navigate to **Language and Input**
- Click the Checkbox next to **1616 Keyboard**

When you open your default Android keyboard, you should now see a button or a notification allowing you to select your input method.

- Select 1616 Keyboard

Now you are able to type with the 1616 Keyboard!

# Features

1616 Keyboard provides full support for:

- Latin alphabet with special characters for all European national and regional languages
- Special encoded fonts for the Latin and Greek alphabet (𝔩𝔦𝔨𝔢 𝔱𝔥𝔦𝔰 ℴ𝓇 𝓉𝒽𝒾𝓈 ᵃⁿᵈ ᵐᵒʳᵉ)
- International Phonetic Alphabet including relevant superscript letters and extensions
- Greek alphabet including polytoniko and archaic letters
- Cyrillic alphabet with special characters for all European (slavic and non-slavic) national and regional languages
- Hebrew script with all diacritics and Yiddish special characters
- Arabic script with all relevant special characters and diacritics (up to Unicode block "Arabic supplement")
- Korean script including automatic composition of syllables
- Georgian alphabet including Asomtavruli and Nuskhuri
- Armenian alphabet
- Tibetan script
- Additional symbols and currency signs
- Widely used mathematical signs and operators
- Combining diacritics including combining diacritics in the International Phonetic Alphabet
